# AQSora Commodity Price Watch

煤炭与腐殖酸价格研究的独立项目。初始数据包含蒙古国 2026 年 7—10 月三类褐煤官方参考价，以及印尼 2026 年 11 月 1—14 日四类 HBA 参考价，共 16 条。数据人工核验日期为 2026-11-09。

## 版本来源

原 ChatGPT 对话中的初始化 ZIP 无法取得。本仓库按对话中描述的功能范围重新实现，所有数值重新核对官方公告。本版为重建版，无法证明与原 ZIP 的文件内容一致。

## 查看与验证

直接下载并用浏览器打开 `docs/index.html` 即可离线查看。网页自带样式和图表，无需安装依赖。

使用 Python 3.11 或更新版本，在仓库根目录执行以下命令。全部功能仅使用标准库。

```sh
python3 scripts/prices.py
python3 -m unittest discover -s tests -v
python3 scripts/build.py --check
```

更新数据后运行 `python3 scripts/build.py` 重建网页，再运行测试与 `--check`。GitHub Actions 在推送、拉取请求或手动触发时执行同样的校验。价格更新采用人工核验，定时抓取和 GitHub Pages 托管尚未启用。

## 使用口径

- 官方参考价用于市场研究，AQSora 实际销售价需通过询价取得。报价适用性需要煤质、交货地、税费、运输及融资成本支持。
- 蒙古国数据以公告月份排列，基础价格观察期为前一个月。8 月正文署期为 10 日，网页发布为 11 日，两者分别保存。
- 印尼公告发表于 11 月 3 日，适用期为 11 月 1—14 日。主类热值在本公告中仅描述为 HPB 用于大于 6000 kcal/kg GAR 的煤种，完整标准需另核部长决定附件。
- `NAR` 与 `GAR` 保持独立口径。涨跌幅只在相同 `series_id` 的相邻已收录记录之间计算，缺期不会补值。首条记录的涨跌幅为空。
- ICI、API、Platts 及腐殖酸报价模板为空，模板不进入看板。授权数据及商业询价可先放入被忽略的 `private/` 目录，公开前检查再发布许可与商业保密要求。

## 更新数据

先核对官方原文的数值、单位、热值口径、规格和日期。将新公告加入 `sources`，将价格加入 `records`，更新实际人工核验日期 `verified_on`。若标准、单位或交货条件发生变化，应新增序列，避免将不同口径拼接。

校验会拒绝重复或重叠期间、非正数、空值、无限值、未来发布日期和来源类别错配。新增官方域名需要先在校验器中审核允许。结构校验不能代替人工核对公告原文。

该仓库独立管理代码、数据和工作流，与现有钢铁新闻及钢铁配额项目分开维护。
